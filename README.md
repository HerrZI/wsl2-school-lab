# wsl2-school-lab
Material für den Lehrkräfte-Workshop **„WSL2-School-Lab“** (60 Minuten, Regionaler Cisco-Akademietag 2026 Niedersachsen): 
- Linux Inhalte unterrichten – auf Windows-Rechnern

## Dateien im Hauptverzeichnis
- `server.log`: Logdatei für die Aufgaben des Arbeitsblatts.
- `wsl-setup-workshop.sh`: Skript zur Einrichtung des Workshops in der eigenen WSL-Instanz.
- `wsl-teardown-workshop.sh`: Skript zum Entfernen bzw. Rücksetzen der Workshop-Umgebung in der eigenen WSL Instanz.

## Unterordner
- `dokumente/`: Arbeitsmaterialien für den Workshop, unter anderem Arbeitsblätter, Handouts, Hilfestellungen, Lösungsblätter und die Präsentation zum Thema.
- `server/`: Skripte und Hilfsdateien zur Einrichtung und zum Rücksetzen der Workshop-Umgebung auf einem Server, inklusive Logdatei.
- `videos/`: Videomaterial für die einzelnen Workshop-Schritte, z. B. WSL installieren, Ubuntu installieren und einrichten, starten und verwenden sowie Klassenimage importieren.
